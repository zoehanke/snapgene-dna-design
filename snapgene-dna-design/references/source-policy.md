# Source policy

Priority order:

1. Manufacturer official product protocols (NEB, Thermo Fisher, Takara, etc.)
2. protocols.io public protocols
3. Addgene general molecular-biology protocols
4. Peer-reviewed papers and supplementary material
5. Blogs/forums/search summaries — never sufficient alone for exact conditions

Forbidden source values: `AI`, `internet`, `latest`, unqualified `verified`.

Every recommendation must carry source_type, name, version/revision when
available, URL, retrieved_at, and verification status from
`verified / partial / unavailable / unknown / conflicting / stale`.
