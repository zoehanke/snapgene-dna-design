# 最后一轮开发文档

依据：[最终发布审查](FINAL-RELEASE-AUDIT-20260907.md)。目标：关闭已复现的使用与正确性问题，保持主通路可操作、结构清晰，交付经真实任务验证的发布包。

## 给项目负责人的说明

这轮重点是让公开入口、计算、检查和最终文件说同一件事。统一已有检查函数，完整引物按完整分子检查，正常输入应直接运行。对确实需要长尾的克隆，优先提供可执行的分步扩增，而不是假报通过或一律拒绝。

## 实施顺序

1. **统一编码检查**：在现有 sequence_ops 中复用 Biopython 做密码表、相位、起止、未知密码子和翻译核验。Recipe 自检、文件验证与独立 CLI 使用同一套 CDS 规则。保留明确的 partial 证据；遗传密码表必须符合来源，不能从失败结果倒推豁免。
2. **修完整引物设计**：实际检查尾部加核心，保留失败原因，优先选择完整指标合格的候选。移除大范围异常吞噬。检查范围或后端不足时不能填入通过。必要的长尾扩增拆为实际 PCR 步骤，每一步使用上一真实产物，并给出源图、引物及中间体。
3. **统一公开接口**：修 topology/circular 参数失配、Pipeline 根列表输入，检查已注册工具的实际参数。修正误导文档；不为未改变的发布 schema 增设迁移层。
4. **修源对象和当前执行结果**：Pipeline 的来源引用加载为完整 SeqRecord；DNA、蛋白翻译与分析结果各按实际类型处理，禁止把文件路径或蛋白报告当 DNA 产物。落地文件再检查 DNA 字母表。Pipeline/ConstructionTask 所有失败路径写入本次失败结果，保留历史文件但不能称为本次交付。文件范围：composite_pipeline、translation、registry、runtime_validate 及对应 CLI。
5. **最终验收与发布**：先跑原反例，再从正常 CLI 重放真实复合任务，独立重建实际扩增与连接结果，检查 Native 文件的序列、注释及完整引物。运行必要回归，打包、验证解压入口并备份更新安装版。

## 完成标准

同一真实输入在各入口得到一致结论；不改目标 DNA 迎合测试；每个制备中间体都能由实际模板和引物推导；正式产物保留注释与拓扑；未评估项不冒充通过。发布结论引用实际任务与文件证据，不承诺数学上证明不存在任何未来缺陷。

状态：开发完成，0.9.4 已打包并更新安装版。已确认的使用与正确性缺陷均有修复及反例复验；本轮不新增 Construct Review 或独立验证引擎。

## 实施结果

1. **编码与注释完成**：共享 CDS 规则、任意区域偏移、双义终止密码表、实际裁剪片段、点突变翻译均已核验。补修跨原点酶切、删除和注释恢复；Q5 重复 AmpR 消除，合法 partial 域保留。
2. **实际制备完成**：完整引物全部进入结构检查；`prepare_pcr_fragment` 支持真实连续 PCR。Q3 长标签两步制备，Q1 七片段和 Q5 三片段通过逐接头方向选择恢复成功，目标 DNA 未改变。旧互补扫描漏算内部连续匹配的问题一并修复。
3. **公开入口完成**：41 个注册工具，参数契约、根列表输入、源对象、分析结果类型和实际拓扑一致；错误输入不能变成 DNA 或被报告为当前交付。
4. **验证完成**：完整回归 734 项，727 通过、7 个可选集成跳过；最后增补代码另跑 `test_final_*.py`，41 项通过。五个资料完整的论文任务通过实际反应重建，10 个 Native 文件经官方 SnapGene 保存回读，序列、拓扑、特征覆盖、链向、名称、提取序列和完整引物一致。Q4 原始材料缺失，不计入通过。
5. **交付完成**：225 个运行文件已冻结并逐文件校验。解压包在仓库外完成七片段 Recipe、实际长尾 PCR Pipeline 及失败重跑检查；另对冻结包 Q5 做三次 PCR、接头、产物及注释独立复核。安装版独立重复长尾 PCR 和失败状态检查。旧版完整备份，未提交或推送 Git。
