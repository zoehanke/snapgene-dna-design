通用空白框架 r3，对应 [design.md](design.md) 的 research-report-v1。上层采用固定外框，以下细分块是可选内容库，不含案例内容，也不新增采集要求。默认展开按 design.md 的人类详情契约呈现；本模板的内部版本、编号及原始字段占位只供作者/技术记录使用，不直接输出给研究者。

最终报告按“我们要做什么？→ 设计怎样形成？→ 本次得到了什么？→ 现在需要处理什么？（有事项时）→ 查看详细记录”组织。开头的背景、用户要求和记录用途合并进入第一节；图形视图是第二节的另一种读法。使用时删除不适用的细分块，按实际过程复制、排序并编号步骤；下面的步骤排列不是规定的发生顺序。`〔占位项〕` 填入真实记录，未记录的内容不得补造。Markdown 详情用附录跳转，未来 HTML 可采用折叠或侧栏。
