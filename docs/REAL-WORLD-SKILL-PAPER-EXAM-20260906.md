## 题 1：七模板 PCR 与完整整合受体组装

用完整 pYTK008、pYTK047、pYTK073、pYTK074、pYTK086、pYTK090、pYTK092 构建一个 URA3 整合受体。保留 URA3 两侧同源区及条形码、完整 URA3 筛选盒、GFP dropout、配套 ConS/ConE 连接件、KanR 和 ColE1，按这些工具包部件的兼容顺序形成闭合质粒。

本题采用 PCR 制备片段、Gibson 组装。请设计全部制备引物，包括骨架来源片段；不要把完整供体直接当作已经制备好的片段。保留供后续换入表达盒使用的限制性位点。提供完整片段链、源文件引物标注和两组诊断酶切预测。

负责人材料依据：[Lee et al., 2015](https://doi.org/10.1021/sb500366v)、[YTK 官方资源](https://www.addgene.org/kits/moclo-ytk/)。成品对照与本次替代制备路线分别保存在考官答案。

## 题 2：三色分层 Golden Gate

用完整 EcoFlex 单部件质粒，先做三个 Level 1 转录单元，再组装一个 Level 2 质粒，顺序为：

1. J23100 → B0034 → eGFP → B0015。
2. J23108 → B0034 → mCherry → L3S2P21。
3. J23114 → B0034 → eCFP → L3S1P51。

从实际文件选择对应层级与位置的受体，使用 EcoFlex 的 BsaI/BsmBI 规则。检查每一条实际序列的切位，不能只相信元件名称或工具包标准。交付三个 Level 1 和一个 Level 2 成品，说明全部末端、接头及占位序列去留，给出含条带长度的诊断酶切。

如果现有受体或末级单元的实际末端不兼容，可增加最少的 PCR 接口改造；必须交付引物和中间体，保留所有其他骨架序列。不得直接编辑源文件后把它当成现成库存。

负责人材料依据：[Moore et al., 2016](https://doi.org/10.1021/acssynbio.6b00031)、[EcoFlex](https://www.addgene.org/kits/freemont-ecoflex-moclo/)。官方荧光供体文件名为 `pBP-eGFP`、`pBP-mCherry`、`pBP-eCFP`。具体三盒组合是本题设定。

## 题 3：GFP 变体分支与融合表达载体

从同一份完整圆形 pBP-eGFP 出发，经定点突变得到 WT、Y66H、Y66H/Y145F 三种 GFP 编码序列。WT 指这份文件的源序列。该记录虽名为 eGFP，实际第 64/65 位是 F/G，不能默认它就是常见 F64L/S65T EGFP。编号以给定 GFP 蛋白参考为准，先对齐源 CDS，不能把额外起始残基或融合标签计入通用编号。

再经双酶切连接分别迁入完整 pET-28a(+)，统一表达 N 端 His6 → TEV 位点 → GFP 变体，GFP 后接终止密码子。排除额外 T7 标签和 C 端 His 标签。三版除指定变体位置外使用相同骨架和融合边界。

交付突变中间体、三版表达质粒、三种完整翻译、变体差异表、制备引物及覆盖突变和接头的验证方案。不得声称这些具体背景下的荧光性能已实测。

负责人材料依据：[Heim and Tsien, 1996](https://pubmed.ncbi.nlm.nih.gov/8673464/)。该文支撑 GFP 突变研究；本题完整 pET 表达构建不是论文原始质粒。

## 题 4：串联荧光计时器替换

从完整 pFA6a-mCherry-sfGFP-kanMX 及经核对的 mNeonGreen 供体出发，将 sfGFP 替换为 mNeonGreen，得到保持 mCherry → linker → mNeonGreen 编码关系的 pFA6a 计时器质粒。保留 kanMX、细菌复制和筛选功能，以及标签载体其余结构。

根据实际材料说明采用酶切骨架加 PCR/Gibson，或对完整骨架进行 PCR 改造。交付真实扩增片段、融合翻译、接头与诊断方案。不能使用计时器最终答案文件作为插入模板。

负责人材料依据：[Fung et al., 2022](https://doi.org/10.1007/978-1-0716-1732-8_6)、[作者计时器](https://www.addgene.org/173453/)。原文用的 pKBJ002.1 完整供体尚未取得，本题暂缓盲测。现有另一份公开 mNeonGreen 虽编码相同蛋白，DNA 不同，不能顶替成品的真实来源。

## 题 5：双表达、四报告的哺乳动物非病毒质粒

用完整 pVH1001 Tier-2 骨架，以及分别含以下表达单元的两份完整供体，合成一个质粒：

- A1：PhCMV → SEAP → P2A → iRFP670 → poly(A)。
- A2：PmPGK1 → Igκ 分泌信号 → Nluc → P2A → mTagBFP2 → poly(A)。

保留 A3 空接收位点及其 poly(A) 背景、原有细菌骨架。请保持每个融合的编码顺序与 P2A 读框，不能把两份完整供体串联成一个冗余骨架。交付完整制备路线、必要中间体、两个完整表达 ORF 和诊断方案。

负责人材料依据：[Haellman et al., 2021](https://doi.org/10.1016/j.ymben.2021.04.003)、[作者集合](https://www.addgene.org/browse/article/28216407/)。输入为 #169599、#169617、#169618，成品参照留在考官目录。

## 题 6：guide 载体、HDR 供体与编辑后等位基因

按提供的 CDC48 局部参考，设计 R105G 编辑，同时加入不改变其他氨基酸的 PAM 修改。制备所提供 pML104 的 guide 版本、90 bp 双链供体和预期编辑后的基因组局部记录。guide 载体通过 PCR 改造与环化获得，不把 Cas9、URA3 或细菌骨架整合进基因组。

交付实际完整引物、供体双链序列、guide 方向和 PAM 检查、完整 CDC48 翻译差异及验证引物。判断野生型与编辑型是否能靠 PCR 长度区分，必要时明确测序判读位点。

本题是固定局部参考上的计算复现。输入使用 S288C RefSeq，论文实际宿主为 BY4741；不能把局部模拟称为已验证作者菌株全基因组，也不要求根据这一份局部记录得出全基因组脱靶结论。

负责人材料依据：[Hu et al., 2018](https://pmc.ncbi.nlm.nih.gov/articles/PMC5868978/)、[pML104](https://www.addgene.org/67638/)。
