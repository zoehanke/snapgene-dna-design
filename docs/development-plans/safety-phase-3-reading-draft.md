# 为荧光比较准备三种 GFP 表达质粒

Reader Demo r3，2026-09-12。项目负责人已明确回复“案例成立，可作为 Reader Demo”。案例适用性已确认；真人计时试读尚未进行，两项状态分别记录。

## 这个研究要解决什么问题？

研究者想比较源 GFP、单突变 Y66H、双突变 Y66H/Y145F，看看这些序列变化在同一表达背景下带来怎样的荧光表现。现在要做的是**准备三份可比较的表达质粒**，后续才测量颜色、亮度和表达量。

这个需求改编自仓库的 [GFP 变体比较任务](../REAL-WORLD-SKILL-PAPER-EXAM-20260906.md)，属于有论文依据的实验设计场景，不是本团队已经完成的荧光实验，也不是 Genome Resurrection 的既定实验支线。

手头材料是一份完整 pBP-eGFP 源质粒和 pET-28a(+) 表达载体。任务要求利用现有模板制备三种变体，统一使用 N 端 His6 和 TEV 切割位点，保留 GFP 的终止密码子，并通过双酶切连接进入同一表达骨架。

## 为什么需要这份 Evidence Trace？

研究者给出目标和材料限制，AI 解释材料并选择构建路线，程序计算反应与检查文件。这份记录让复核者分清：**哪些是任务要求，哪些是 AI 的取舍，哪些有文献依据，哪些只经过计算检查。** 最后拿到质粒文件，并不等于已经知道它的荧光表现。

**当前可核查的结果：** 历史工程任务保存了三份同背景的表达质粒。本次读回确认三份均为 5,995 bp 环形 DNA；相对源对照，两种变体分别相差 1 和 2 个碱基。仍需实验确定荧光表现。本次没有重新执行完整克隆流程。

## 设计为什么这样形成？

### 1. 先确定“源 GFP”指什么

**任务要求：** 从手头完整源质粒出发，不用新合成片段代替来源。

**AI 本次提出的选择：** 以这份文件的实际编码序列作为对照，不因为文件名含 eGFP 就换成标准 EGFP 序列。

**理由：** 仓库已有来源核查指出，这份记录并不是常见的 F64L/S65T EGFP 背景。如果悄悄替换为另一种“标准序列”，比较对象就变了，论文中的结果也可能被套用到不相同的材料上。

这里值得审查的是“用哪个生物学背景作比较”。来源核查与具体差异保留在 [参考设计记录](../REAL-WORLD-SKILL-REFERENCE-ANSWERS-20260906.md)。本例的 WT 只表示源序列对照。

### 2. 为什么保留单突变和双突变两个分支？

**任务要求：** 同时准备源对照、Y66H 和 Y66H/Y145F。

**AI 本次提出的选择：** 保留三组，先用真实模板制备 Y66H，再以它的实际产物制备双突变；不直接把单突变分支替换掉。

**理由：** 单突变与双突变的比较可以帮助研究后续差异是否与新增的 Y145F 有关，源对照则保留起始背景。文献研究过 Y66H/Y145F 蓝色变体，但不能证明本任务的新表达构建一定具有同样表现。[Wachter et al., 1997](https://pubmed.ncbi.nlm.nih.gov/9245407/)

**证据边界：** 文献支持候选的研究动机，不代替当前宿主、序列背景、标签和测量条件下的实验。不能在没有本任务数据时写“双突变一定更好”。

### 3. 为什么采用相同载体和标签？

**任务要求：** 都迁入 pET-28a(+)，使用相同 His6/TEV 连接方式，不额外翻译出 T7 或 C 端 His 标签。

**AI 本次提出的选择：** 固定共同表达背景，只保留要求比较的变体差异；按相同连接边界制备三份插入片段。

**理由：** 如果同时改变载体、标签和 GFP 序列，后续差异就更难归因。统一这些设计条件有助于比较，但表达量、成熟过程等仍可能影响荧光读数。

**程序需要确认：** 片段来源、实际扩增产物、连接位置和方向、完整翻译、终止位置，以及三版之间是否出现额外差异。看到“序列中还有 His 编码片段”与“蛋白会表达 C 端 His”不是一回事，需核对终止位置。

### 4. 哪些结果已经存在，哪些还没有？

历史工程任务已生成三种正式表达质粒及制备、验证记录。旧报告记录了实际 PCR、酶切连接与构建核验；本次仅对保存文件做读回检查，不能当作重跑全部程序 Validation。[历史完成记录](../FINAL-RELEASE-AUDIT-20260907.md)

| 文件组 | 本次确认的文件事实 | 它不能单独确认什么 |
|---|---|---|
| 源对照 WT | 5,995 bp，环形，融合 CDS 762 bp | 是否适合当前荧光测量 |
| Y66H | 同长度、同拓扑，相对源对照 1 个碱基差异 | 当前条件下的颜色和亮度 |

```text
   │  └─ 选择：核对实际背景，不凭文件名替换序列
   ├─ 比较目标：源对照 / Y66H / Y66H+Y145F

   │  └─ 依据：文献提供候选动机，不保证本构建表现
   ├─ 可比性约束：共同载体、标签和融合边界
   │  └─ 选择：三份按同一表达结构制备
   ├─ 工程证据：历史程序记录 + 本次文件读回
   └─ 三份变体文件 → 下一步测量荧光，复核条件适用性
```

## 现在要复核什么？

1. **比较对象是否正确？** 看真实源序列及三版差异，不把源文件名称当作标准 EGFP 身份证明。
2. **证据是否适用于当前实验？** 看论文实际材料与任务的宿主、序列背景、标签和测量条件；未确定的地方继续留空。
3. **设计是否按预期落到文件？** 从变体名称回到对应文件、翻译和历史程序检查；确认采用的正是那一版。
4. **哪些问题要做实验？** 当前材料的荧光表现、表达量及条件影响不能由文件检查回答。
