## 真人先检查这五件事

1. **交付是否齐。**能打开实际文件，有要求的中间体、引物和方案。不能只交一张图、一个序列摘要或一个“PASS”。
2. **结构是否对。**在SnapGene中按模块顺序查看，确认方向、接口、完整编码区、终止位置及要保留的骨架。
3. **引物是否真能做。**将完整订购引物放到它声称的完整模板上模拟PCR；区分3′结合区与5′附加序列。核对产物及其后续酶切/组装，不把目标片段直接当PCR产物。
4. **后一步是否继承前一步。**看原始调用记录中的实际模板文件，再比对DNA；不要只相信AI的步骤说明。第4、8题尤其要查。
5. **验证能否识别错误。**接口PCR、整段测序或诊断酶切需覆盖本题真正的错误风险；一个所有版本都阳性的PCR不能区分版本。

**比对注意：**环形质粒可以换起点；整环反向表示也可接受，但功能方向和注释必须一起正确转换。长度相同不代表序列正确。不同引物、合理制备边界或题面允许的密码子可以不同；未授权的额外DNA变化不能用“路线不同”解释。

结果只需记为：**通过 / 未完成 / 不通过 / 暂不能判定**，并写一句具体原因。缺输入材料不能算AI失败；有效任务被无根据拒绝也不能算完成。
