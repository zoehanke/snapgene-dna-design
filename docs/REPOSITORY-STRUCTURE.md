# Repository structure

This repository is the single active development location for SnapGene DNA
Design. Version folders are not used for development. Use branches and tags.

## Tracked here

- source modules under `agent/`, `core/`, `planning/`, and `scripts/`
- schemas, rules, references, tests, and synthetic fixtures
- user-facing documentation and architecture decisions

## Kept outside the repository

- release ZIPs and SHA-256 archives
- audit reports and blind-test truth files
- user DNA and restricted SnapGene-derived fixtures
- generated logs, caches, model outputs, and temporary files

The current imported baseline is `0.9.1-dev1` and remains a development
baseline. It is not a release claim.
