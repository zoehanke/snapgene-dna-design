# v1.0.0：可用大版本

发布日期：2026-09-08。此版本将已验证的 0.9.4 计算实现提升为首个可用大版本，不再修改反应算法。

## 可用功能

- 7 个 Recipe、41 个原子工具及多步 Pipeline。
- 从实际模板和完整引物推导 PCR 产物；长尾采用真实连续 PCR，交付各步模板、引物及中间体。
- Gibson 逐接头选择同源尾方向，支持真实多片段制备。
- 正确处理跨原点酶切、编辑、复合特征与 CDS；保留骨架、新插入片段及引物注释。
- 输出经过检查的 `.dna`、GenBank 与 FASTA。失败重跑不会把历史成功误报为本次交付。

## 已验证范围

完整回归 734 项：727 通过，7 项可选集成跳过。最后补修另有 41 项相关检查通过，两轮数量不相加冒充功能覆盖。

Q1 七片段受体、Q2 多级 Golden Gate、Q3 GFP 变体与长标签克隆、Q5 双表达、Q6 HDR 与导向载体完成实际反应复核；10 个 Native 文件经官方 SnapGene 保存回读，序列、拓扑、特征与完整引物一致。Q3、Q5 的源注释更正保留了原 DNA 和变更记录。

Q4 缺原始材料未测；可选模型、在线服务及湿实验成功率不在已验证范围。

详细证据：[最终审查](FINAL-RELEASE-AUDIT-20260907.md)、[开发完成记录](FINAL-RELEASE-DEVELOPMENT-20260907.md)。
