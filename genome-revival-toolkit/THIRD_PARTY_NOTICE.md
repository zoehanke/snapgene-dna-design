# Sources and licences

Genome Revival Toolkit uses the repository's SnapGene DNA Design Core, originating from Core 2.2.1 and subsequent documented corrections. The current 0.2.0 candidate bundles Core 2.2.4 and Evidence Trace 0.3.4 from the same reviewed source commit, not an independently maintained implementation. Its MIT licence and third-party notices are retained under `vendor/dna-design-core/`.

Biopython, Primer3 and other runtime dependencies retain their own licences. Exact dependency versions are in the bundled `requirements-tested.txt`; any copied third-party code retains its upstream licence files and notices. `TOOLKIT-MANIFEST.json` records every included file's source and hash.

User DNA, paper-derived task answers and private experimental files are not distributed. Project reference accessions and publications are metadata, not proof of the supplied experimental strain. Download/use of external reference data requires checking its provider terms separately.

Code and documentation were prepared with OpenAI Codex assistance. Exact development model identifiers were not established in the audit and are not inferred from nicknames. Normal host tests, when performed, identify their provider/model configuration and retained session separately. AI assistance does not constitute human experimental validation or authorship of new scientific results.
